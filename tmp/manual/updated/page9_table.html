7. Frequently Asked Questions

1. Gaano katagal ang franchise validity?
Ang MTOP workflow ay para sa tatlong taon. Tingnan ang start at expiration dates sa approved certificate.

2. Ano ang LLSA I?
Local Legislative Staff Assistant I; ito ang SB staff role sa franchising workflow.

3. Maaari bang mag-apply gamit ang cellphone?
Oo. Buksan ang system sa mobile browser at mag-upload ng malinaw na requirements.

4. Paano ive-verify ang certificate?
I-scan ang QR code sa issued certificate at suriin ang record sa official verification page.

5. Maaari bang mag-print ng blank form?
Buksan ang blank-form preview at piliin ang Print / Save as PDF.

6. Paano mag-request ng cancellation?
Piliin ang Request Cancellation sa unit options. Ilagay ang dahilan, i-upload ang signed request, at isumite. Bayaran ang ₱50 cancellation fee sa Treasury at itabi ang O.R.
