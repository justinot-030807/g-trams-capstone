# 🚀 Post-Capstone Production Deployment Checklist

**IMPORTANT WARNING:** 
Ang mga credentials na kasalukuyang nakalagay sa `.env` file ay **COMPROMISED** at nakita nang naka-plaintext sa audit. Para hindi maantala ang inyong Capstone defense at testing, hinayaan muna itong gumagana. 

Bago i-turn over ang system sa LGU (Municipality of Gasan) o bago i-deploy para sa tunay na mga tricycle drivers, **KAILANGANG PALITAN (ROTATE)** ang mga sumusunod na credentials.

---

## 🔐 1. Credential Rotation (Mga Kailangang Palitan)

### A. MongoDB Database (`MONGO_URI`)
- **Bakit:** Kung may makakuha ng current URI, pwede nilang i-delete, nakawin, o palitan ang lahat ng records ng prangkisa.
- **Paano:**
  1. Mag-login sa [MongoDB Atlas](https://cloud.mongodb.com/).
  2. Pumunta sa **Database Access** sa left menu.
  3. I-edit ang user na `lachica_3e` at palitan ang password.
  4. I-update ang connection string sa inyong production environment.

### B. Cloudinary (`CLOUDINARY_API_SECRET`)
- **Bakit:** Pwedeng burahin ng iba ang mga uploaded na OR/CR, resibo, at picture ng mga drivers.
- **Paano:**
  1. Mag-login sa [Cloudinary Dashboard](https://cloudinary.com/).
  2. Pumunta sa **Settings** (Gear icon) -> **Access Keys**.
  3. Mag-generate ng bagong API Secret. (Palitan ang `CLOUDINARY_API_SECRET` at `CLOUDINARY_API_KEY`).

### C. Semaphore SMS (`SEMAPHORE_API_KEY`)
- **Bakit:** Pwedeng gamitin ng iba ang account ninyo para mag-spam ng text messages, uubusin ang credits ninyo.
- **Paano:**
  1. Mag-login sa [Semaphore Dashboard](https://semaphore.co/).
  2. Pumunta sa **Settings** -> **API**.
  3. I-regenerate ang API key at i-update sa server.

### D. System Email (`EMAIL_PASS`)
- **Bakit:** Ang Gmail App Password na nakalagay ay pwedeng gamitin para ma-hijack ang system email.
- **Paano:**
  1. Pumunta sa [Google Account Security](https://myaccount.google.com/security) ng GTRAMS email.
  2. Pumasok sa **2-Step Verification** -> **App Passwords**.
  3. I-delete ang lumang password at gumawa ng bago (Pangalanang "GTRAMS Prod Server").

### E. Web Push Keys (`VAPID_PUBLIC_KEY` & `VAPID_PRIVATE_KEY`)
- **Bakit:** Para walang makapag-padala ng fake push notifications sa mga phones ng drivers.
- **Paano:**
  - Mag-run ng command na ito sa backend folder: `npx web-push generate-vapid-keys`
  - Kopyahin ang bagong Public at Private keys.

---

## 🌍 2. Environment Setup (Render / Vercel)

Huwag na huwag mag-upload ng `.env` file sa GitHub. Kapag nag-deploy na sa production:
1. Pumunta sa **Render Dashboard** (para sa backend).
2. Pumunta sa inyong Web Service -> **Environment**.
3. Ilagay nang isa-isa ang mga bagong keys doon, kasama ang inyong bagong `JWT_SECRET`.
4. Gawin din ang kapareho sa **Vercel Dashboard** (para sa frontend) kung may mga `VITE_` variables kayong kailangang itago.
