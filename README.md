# G-TRAMS: Gasan Tricycle Records and Application Management System

Web-based MTOP (Motorized Tricycle Operator's Permit) application, renewal, municipal treasury payment, voluntary cancellation, progressive violation discipline, and TODA roster management platform for the **Municipality of Gasan, Marinduque** (Office of the Municipal Vice Mayor / LLSA I & Municipal Treasury).
